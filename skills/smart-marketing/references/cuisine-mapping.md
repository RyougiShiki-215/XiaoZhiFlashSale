# 场景B references/：菜系 → 口味偏好 / 人群特征映射知识库

> **使用说明**：
> - 此文件在 Skill 第二步「用户偏好提炼 + 商家匹配」阶段**读取一次**。
> - 用途：当用户画像/历史订单里出现某个菜系标签时，按本表推断更细的口味偏好，
>   从而给出更精准的推荐理由（例如：历史订单有「火锅」→ 不仅知道爱吃川菜，还推断「喜欢围餐分享、能吃辣、聚餐场景多」）。
> - 运营可随时修改此文件扩展菜系覆盖，无需改 skill.md 正文。

## 🚫 忌口推断辅助表（用户画像出现忌口时，反向剔除匹配商家）
| 忌口标签 | 必须剔除的菜系/菜品 | 替代推荐方向 |
|---|---|---|
| 海鲜过敏 | 日料刺身、海鲜火锅、虾蟹菜品、烤鱼（部分含虾酱） | 川菜/湘菜/鲁菜/素食，明确避开虾、蟹、贝类、鱿鱼 |
| 不吃辣 | 川菜、湘菜、麻辣香锅、火锅（红锅）、韩餐部队锅 | 粤菜、江浙菜、鲁菜、西式快餐、日料（非芥末款） |
| 素食 / 不吃肉 | 所有荤菜、含肉高汤、烤鱼、烤肉 | 素食馆、沙拉、轻食、麻辣香锅（全素）、面点 |
| 香菜 / 芹菜 / 葱 等具体食材 | 直接在推荐菜品描述中**不要提该食材** | 改说"配料可自由调整，不吃香菜可以备注" |
| 乳糖不耐 | 芝士披萨、奶油意面、奶茶（含奶）、酸奶 | 黑咖啡、水果茶、意面（番茄底）、纯茶 |
| 糖尿病 / 控糖 | 甜点、奶茶、可乐、糖醋类菜 | 无糖茶饮、沙拉、清淡菜、明确说"无糖/少糖" |
